📌 About the Project

Seavari is a web-based initiative designed to spread awareness about ocean conservation, marine biodiversity, and pollution prevention.

The platform encourages individuals and communities to understand the challenges facing our oceans and take meaningful steps towards protecting marine ecosystems.

Through educational resources, pollution awareness, marine species reporting, and community engagement, Seavari aims to inspire people to become responsible ocean protectors.

🎯 Objectives

- Promote awareness about marine pollution and its environmental impact.
- Educate people about marine biodiversity and ocean ecosystems.
- Encourage reporting and documentation of marine species.
- Support community participation in ocean conservation.
- Promote sustainable practices to protect aquatic life.

✨ Key Features

1. 🐠 Explore Ocean Life

Provides an introduction to marine biodiversity and encourages users to learn about different ocean species and ecosystems.

2. 🌍 Track Pollution

Raises awareness about major forms of ocean pollution, including:

- Plastic Pollution
- Chemical Contamination

3. 🐢 Report Marine Species

Provides a reporting interface where users can submit:

- Name
- Species Name
- Location Found
- Additional Observations

This feature is intended to encourage awareness and documentation of marine biodiversity.

4. 📚 Educational Resources

Promotes ocean literacy through educational videos, blogs, and informative content about marine ecosystems and environmental challenges.

5. 📢 Raise Awareness

Encourages conservation through:

- Educational Campaigns
- Social Media Engagement
- Ocean Literacy Resources

6. 🤝 Join Us

Provides a community engagement interface where visitors can express their interest in supporting ocean conservation.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/Dhruvr245/Seavari.git

2. Navigate to the project directory

cd Seavari

3. Open the website

Open "Seavari.html" in your preferred web browser.

Note: Ensure the stylesheet reference in "Seavari.html" points to "Seavari.css" for the styling to load correctly.
