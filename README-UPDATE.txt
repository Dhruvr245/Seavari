SEAVARI FULL WEBSITE UPDATE

This package restyles the complete static website using the same ocean-blue visual language as the existing pollution.html page: ocean blue #1B4965, bright blue #0077B6, cyan headings, dark blue panels, and white chart panels.

ANDROID INSTALLATION
1. Extract this ZIP on your phone.
2. Open https://github.com/Daiss216/Seavari-website
3. Upload the files from this folder to the repository root.
4. Replace matching files when prompted.
5. Add new files report.html, awareness.html, and contact.html.
6. Do not upload this ZIP as a website file.
7. Commit to main and wait for GitHub Pages to deploy.
8. Refresh https://daiss216.github.io/Seavari-website/

Keep all files in the repository root. Keep filenames exactly as written, including debries.html. The dashboard uses Leaflet/OpenStreetMap and Chart.js from public CDNs. Values are demo data, not live measurements. Forms are frontend demos and are not connected to a backend. This package does not delete repository history.
